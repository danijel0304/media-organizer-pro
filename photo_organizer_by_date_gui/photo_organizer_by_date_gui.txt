📸 Photo Organizer Pro
Organizirajte fotografije automatski po godini snimanja!

Photo Organizer Pro je moćan alat za organizaciju digitalnih fotografija koji automatski sortira slike u mape po godini snimanja na temelju EXIF meta podataka ili datuma kreiranja datoteke.

✨ Glavne značajke
🔍 Automatska detekcija datuma - čita EXIF podatke ili datum kreiranja

📁 Pametno sortiranje - organizira u mape po godinama

🎨 Moderan GUI - intuitivno i lijepo korisničko sučelje

📊 Detaljan pregled - prikaz statistike po godinama

⚡ Brza obrada - podržava multithreading

📝 Detaljni log - bilježi sve radnje

⚠️ Prepoznavanje problema - poseban pregled za slike bez datuma

📋 Podržani formati slika
JPEG/JPG

PNG

GIF

BMP

TIFF

WebP

HEIC

RAW (CR2, NEF, itd.)

🚀 Instalacija
Prvi put koristite?
Preuzmite Python (ako ga već nemate):

Preuzmite s python.org

Pri instalaciji obavezno označite "Add Python to PATH"

Instalirajte potrebne pakete:

bash
pip install Pillow ttkbootstrap
Pokrenite program:

bash
python photo_organizer_gui.py
🎮 Kako koristiti
Korak po korak:
Pokrenite program

Odaberite izvornu mapu - mapa gdje se nalaze vaše fotografije

Odaberite odredišnu mapu - gdje će se kreirati organizirane mape

Kliknite "Analiziraj fotografije" - program će pregledati sve slike

Pregledajte rezultate u karticama:

📊 Pregled po godinama - koliko slika ima za svaku godinu

📝 Detaljni log - sve radnje i poruke

⚠️ Bez datuma - slike koje nije mogao obraditi

Kliknite "Organiziraj fotografije" - izvršite sortiranje

📂 Kako funkcionira
Čitanje EXIF podataka - prvo pokušava pročitati datum snimanja iz EXIF meta podataka

Alternativni datum - ako nema EXIF podataka, koristi datum kreiranja datoteke

Kreiranje mapa - za svaku godinu kreira posebnu mapu u odredišnoj mapi

Premještanje - premješta slike u odgovarajuće mape

Jedinstvena imena - ako već postoji slika s istim imenom, automatski dodaje broj

❓ Često postavljana pitanja
P: Mijenja li program originalne slike?
O: Ne, samo ih premješta u nove mape. Sadržaj slika ostaje netaknut.

P: Što ako dvije slike imaju isto ime?
O: Program automatski dodaje broj na kraj imena (npr. slika_1.jpg, slika_2.jpg).

P: Mogu li otkazati operaciju?
O: Da, možete otkazati bilo kada klikom na X gumb.

P: Koliko vremena treba za organizaciju?
O: Ovisi o broju slika. 1000 slika treba ~1-2 minute.

P: Radi li na Mac ili Linux?
O: Da, program radi na svim operativnim sustavima (Windows, macOS, Linux).

⚠️ Upozorenja
Uvijek napravite sigurnosnu kopiju prije korištenja bilo kojeg alata za organizaciju

Program ne može vratiti slike na izvorne lokacije automatski

Slike bez datuma ostaju u izvornoj mapi

Program ne podržava video datoteke

🐛 Rješavanje problema
Problem: "ModuleNotFoundError: No module named 'PIL'"
Rješenje: Instalirajte Pillow:

bash
pip install Pillow
Problem: Program se zatvara nakon pokretanja
Rješenje: Pokrenite iz naredbenog retka da vidite pogrešku:

bash
python photo_organizer_gui.py
Problem: Slike se ne premještaju
Rješenje: Provjerite imate li dopuštenje za pisanje u odredišnu mapu.

Problem: Datumi su pogrešni
Rješenje: Provjerite EXIF podatke slike pomoću drugog programa.
