🎬 Video Organizer Pro - README
Organizirajte video datoteke automatski po godini snimanja!

Video Organizer Pro je moćan alat za organizaciju digitalnih video datoteka koji automatski sortira video zapise u mape po godini snimanja na temelju meta podataka ili datuma kreiranja datoteke.

✨ Glavne značajke
🎥 Automatska detekcija datuma - čita video meta podatke (FFprobe) ili datum kreiranja

📁 Pametno sortiranje - organizira u mape po godinama

🎨 Moderan GUI - intuitivno i lijepo korisničko sučelje

📊 Detaljan pregled - prikaz statistike po godinama

⚡ Brza obrada - podržava multithreading

📝 Detaljni log - bilježi sve radnje

⚠️ Prepoznavanje problema - poseban pregled za video datoteke bez datuma

🔍 Podrška za FFprobe - čita precizne meta podatke iz videa

📋 Podržani video formati
Uobičajeni formati:
MP4, AVI, MKV, MOV, WMV

FLV, WebM, M4V

3GP, 3G2, F4V

Specijalni formati:
MTS, M2TS (AVCHD)

TS, MXF (profesionalni formati)

VOB (DVD)

DV, DivX, Xvid

Ukupno preko 20 podržanih formata!
🚀 Instalacija
1. Preduvjeti:
Python 3.6+ (preuzmite s python.org)

FFmpeg (opcionalno, ali preporučeno):

bash
# Windows: Preuzmite s https://ffmpeg.org/download.html
# Linux (Debian/Ubuntu): sudo apt install ffmpeg
# macOS: brew install ffmpeg
2. Instalirajte potrebne Python pakete:
bash
pip install ttkbootstrap
3. Pokrenite program:
bash
python video_organizer_gui.py

1. Detekcija datuma:
FFprobe metoda (ako je instaliran): čita creation_time iz video meta podataka

Sustavna metoda: koristi datum kreiranja/modifikacije datoteke

2. Organizacija:
Kreira mape po godinama (npr. 2020, 2021, 2022)

Premješta video datoteke u odgovarajuće mape

Automatski rješava duplikate imena

3. Sigurnosne mjere:
Prikazuje pregled prije premještanja

❓ Često postavljana pitanja
P: Zašto trebam FFmpeg?
O: FFmpeg (FFprobe) omogućuje čitanje preciznih datuma snimanja iz video meta podataka. Bez njega se koristi samo datum datoteke koji je manje pouzdan.

P: Mijenja li program video datoteke?
O: Ne, samo ih premješta. Kvaliteta i sadržaj ostaju isti.

P: Što ako dvije video datoteke imaju isto ime?
O: Program automatski dodaje broj (npr. video_1.mp4, video_2.mp4).

P: Koliko vremena treba za organizaciju?
O: Ovisi o broju i veličini datoteka. 100 video datoteka treba ~2-5 minuta.

P: Radi li na svim operativnim sustavima?
O: Da! Windows, macOS i Linux su podržani.

⚠️ Upozorenja i ograničenja
Uvijek napravite sigurnosnu kopiju!

Ograničenja:
Ne mijenja video datoteke

Ne organizira audio datoteke

Ne preimenuje datoteke osim u slučaju duplikata

Video bez datuma ostaje u izvornoj mapi

🐛 Rješavanje problema
Problem: "FFprobe nije prepoznat"
bash
# Windows: Dodajte FFmpeg u PATH varijablu
# Linux: sudo apt install ffmpeg
# macOS: brew install ffmpeg
Problem: Program se zatvara
bash
# Pokrenite iz terminala:
python video_organizer_gui.py
# Pogledajte grešku u terminalu
Problem: Datumi su pogrešni
Provjerite ima li video meta podataka

Pokušajte s drugim video preglednikom

Video možda nema pohranjene meta podatke

Problem: Nemam dovoljno prostora
Oslobodite prostor na disku

Odaberite drugi odredišni disk

Organizirajte u manjim grupama

🔄 FFprobe vs Sistemski datum
Karakteristika	FFprobe metoda	Sistemski datum
Točnost	Visoka (meta podaci)	Niska (datoteka)
Instalacija	Potrebna FFmpeg	Ugrađeno
Brzina	Sporija	Brža
Podržani formati	Svi FFmpeg formati	Svi formati
Pouzdanost	Vrlo pouzdana	Manje pouzdana
