## ✨ Karakteristike

### 🔍 **Napredna Detekcija**
- **Dvije metode detekcije**: po imenu datoteke ili MD5 hash-u
- **25+ video formata**: MP4, AVI, MKV, MOV, WMV, FLV, WebM, itd.
- **Rekurzivno skeniranje**: analiza svih podfoldera
- **Multi-NAS podrška**: više referentnih foldera

### 🎨 **Moderno GUI Sučelje**
- **Tamna tema** s modernim dizajnom
- **Thumbnail pregled** video datoteka
- **Checkbox odabir** pojedinačnih datoteka
- **Real-time statistike** i napredak
- **Intuitivni tabovi** za organizaciju

### ⚙️ **Upravljanje Duplikatima**
- **Selektivno brisanje** odabranih datoteka
- **Premještanje u folder** s automatskim rješavanjem duplikata imena
- **Detaljni izvještaji** o svim operacijama
- **Log datoteke** za praćenje promjena

### 📊 **Informacije i Statistike**
- **Veličina datoteka** u realnom vremenu
- **Ukupan broj duplikata**
- **Odabrane datoteke** s ukupnom veličinom
- **Video preview** prvog okvira

## 🚀 Brzi Početak

### 📋 Preduvjeti
- **Python 3.7** ili noviji
- **OpenCV** za video preview (opcionalno)

### 🔧 Instalacija
```bash
# 1. Kloniraj repozitorij
git clone https://github.com/vas-username/video-duplicate-remover.git
cd video-duplicate-remover

# 2. Instaliraj ovisnosti
pip install -r requirements.txt

# 3. Pokreni aplikaciju
python video_duplicate_remover_gui.py

📖 Korištenje
1. Dodaj NAS Foldere
Klikni "📁 NAS Folders" tab

Pritisni "+ Add NAS Folder" za dodavanje referentnih foldera

Ovi folderi će sadržavati originalne datoteke

2. Odaberi Folder za Provjeru
Klikni "🔍 Check Folder" tab

Odaberi folder koji želiš očistiti od duplikata

Postavi opcije:

✅ Deep Check (MD5 Hash) - točnija ali sporija detekcija

✅ Include Subfolders - skeniraj sve podfoldere

✅ Show Video Preview - prikaži thumbnail pregled

✅ Create Log File - generiraj log datoteku

3. Pokreni Skeniranje
Pritisni "🔍 SCAN FOR DUPLICATES"

Čekaj dok se završi analiza

Pregledaj pronađene duplikate

4. Upravljaj Duplikatima
Odaberi datoteke checkbox-ovima

Pregledaj video klikom na datoteku

Odaberi akciju:

🗑️ DELETE SELECTED - trajno obriši

📁 MOVE SELECTED - premjesti u drugi folder

Duplicate Handling: Automatsko rješavanje duplikata imena
