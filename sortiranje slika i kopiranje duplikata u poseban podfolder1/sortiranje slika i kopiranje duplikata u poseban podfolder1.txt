🚀 Instalacija
📋 Preduvjeti
Python 3.6 ili noviji

Tkinter (obično dolazi s Python instalacijom)

🔧 Instalacija ovisnosti
bash
# Kloniraj repozitorij
git clone https://github.com/tvoj-username/organizator-slike-pro.git

# Navigiraj u direktorij projekta
cd organizator-slike-pro

# Instaliraj potrebne biblioteke
pip install pillow
💡 Korištenje
1. Pokretanje programa
bash
python organizator_slika_pro.py
2. Osnovni koraci
Odaberi izvorni direktorij - folder sa slikama koje želiš organizirati

Odaberi odredišni direktorij - folder gdje će se organizirane slike spremiti

Postavi opcije prema svojim potrebama

Pritisni gumb "Pokreni organizaciju slika"

3. Konfiguracijske opcije
📁 Direktoriji
Izvorni direktorij: Lokacija s originalnim slikama

Odredišni direktorij: Lokacija za organizirane slike

⚙️ Osnovne opcije
📋 Kopiraj: Zadrži originalne datoteke

📂 Podmape: Uključi sve podfoldere

🗑️ Obriši originale: Ukloni izvorne datoteke nakon obrade

💾 Backup: Stvori sigurnosnu kopiju

🎨 Filtri i formati
📅 Sortiraj po: Godina, mjesec, datum, kamera, lokacija, rezolucija, veličina

🖼️ Format slika: Svi, JPG/JPEG, PNG, RAW, HEIC, GIF, TIFF, WebP

📏 Veličina filter: Minimalna i maksimalna veličina u MB

✏️ Preimenovanje
Predlošci: 10 unaprijed definiranih šablona

Varijable:

{YYYY} - Godina

{MM} - Mjesec

{DD} - Dan

{HH} - Sati

{mm} - Minute

{ss} - Sekunde

{index} - Redni broj

{randomid} - Random ID

{kamera} - Model kamere

{lokacija} - Lokacija (ako je dostupna u EXIF)

{dan} - Naziv dana

{sequenceid} - ID sekvence

🔧 Napredne opcije
✔️ Preimenuj: Preimenuj datoteke prema šablonu

📂 Zadrži strukturu: Očuvaj hijerarhiju foldera

🚫 Preskoči male: Preskoči male datoteke

📋 Generiraj log: Stvori log datoteku obrade

🔄 Ukloni duplikate: Detektiraj i obradi duplikate

📝 Originalna imena: Zadrži originalna imena datoteka

🌟 Dodatne funkcije
🎨 Kompresija: Komprimiraj slike (planirano)

🖌️ Vodotisak: Dodaj vodotisak (planirano)

🔧 Tehnički Detalji
🏗️ Arhitektura
Glavni proces: Threading za nesmetano korisničko iskustvo

EXIF čitanje: Koristi PIL/Pillow za metapodatke

Hash izračun: MD5 za detekciju duplikata

GUI: Tkinter s modernim temama

📁 Podržani formati
Format	Podrška	Napomene
JPG/JPEG	✅ Potpuna	Uključujući EXIF podatke
PNG	✅ Potpuna	Podržana transparencija
HEIC	✅ Potpuna	Za Apple uređaje
RAW	✅ Djelomična	Zavisno o kodeku
GIF	✅ Potpuna	Animirani i statični
TIFF	✅ Potpuna	Visoka kvaliteta
WebP	✅ Potpuna	Moderni format
